# v0.1 Scope

The public v0.1 core is a frozen, tested subset of the archive-analysis
engine. Phase 3 is out of scope for v0.1.

## Included in v0.1

- **Configuration and workspace discovery** — `engine.engine_config`
  (fail-closed workspace configuration validation).
- **Archive intake** — `engine.inspect_archive`
  (bounded sampling, privacy risk flags, inventory generation).
- **Phase 1 report generation** — `engine.build_phase1_reports`
  (manifest, privacy risk report, processing plan, status; source/root
  redacted, LF-only output).
- **Phase 1 verification** — `engine.verify_phase1`
  (inventory reconciliation and synthetic privacy canary checks; fails
  closed on missing or corrupted required outputs).
- **Phase 2 selective staging** — `engine.phase2_stage`.
- **Phase 2 structural indexing** — `engine.phase2_index`
  (with provenance hash enforcement).
- **Synthetic fixture support** — `tests/fixtures/` (fabricated export
  data; no real archive content).
- **Tests** — `tests/` proving the components above end to end
  (intake → reports → verification, staging, indexing, fixture red-path).

## Intentionally excluded

- **Phase 3 remains private/deferred:** corpus primitives, batch
  processing, statistics, and Phase 3 report building are not part of
  v0.1 and stay in the private repository.
- **Proprietary/private validation layers are not part of v0.1:** the
  independent Phase 2 validator and the Phase 3 validation/build stack
  await a separate licensing decision before any publication.
- **Phase 3B / lens analysis** is a separate product-layer decision and
  stays private.
- **Runtime and personal data** are never published: generated outputs,
  real archive inventories, databases, and personal findings are
  gitignored and regenerable only from private sources.
